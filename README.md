# DataMiner Docs

Open-source source files for the [docs.dataminer.services](https://docs.dataminer.services/) documentation portal.

## Overview

This repository contains the Markdown content, assets, and supporting documentation for DataMiner guides, tutorials, release notes, and solution documentation.

## Repository layout

- [`index.md`](index.md) - landing page content for the documentation portal.
- [`dataminer/`](dataminer) - core DataMiner product documentation.
- [`develop/`](develop) - developer-focused guidance.
- [`connectors/`](connectors) - connector documentation.
- [`solutions/`](solutions) - solution documentation.
- [`tutorials/`](tutorials) - tutorials and learning content.
- [`release-notes/`](release-notes) - release notes.

## Getting started

- Read the published documentation on [docs.dataminer.services](https://docs.dataminer.services/).
